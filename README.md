## 📖 Описание проекта

Проект представляет собой программу с графическим интерфейсом для подбора комнатных растений с помощью **нечеткого логического вывода**. Система принимает условия помещения и возможности пользователя (освещенность, время на уход, температура), а на выходе дает числовую оценку и ближайшее подходящее растение.

Реализованы две задачи:

* **Задача 1 (1 вход).** Освещенность комнаты → потребность растения в свете. 7 правил.
* **Задача 2 (3 входа).** Освещенность, время на уход, температура → капризность растения. 9 правил.

## ✨ Особенности системы

* **Разделение базы знаний и программы:** переменные, нечеткие множества и правила хранятся в текстовых файлах и загружаются динамически, можно открыть любой свой файл.
* **Три механизма вывода:**
  * композиционный (max-min) с первоначальным вычислением выходов правил (алгоритм 1 лекции),
  * композиционный (max-min) с первоначальной агрегацией правил (алгоритм 2 лекции),
  * вывод по уровням истинности предпосылок (алгоритм 3 лекции).

  Композиционные механизмы доступны только для задачи с одним входом; для нескольких входов используется вывод по уровням истинности.
* **Две импликации:** Мамдани `min(α, b)` и Ларсена `α·b`.
* **Три оператора агрегации:** максимум (по умолчанию), ограниченная сумма `min(1, a + b)`, вероятностная сумма `a + b − a·b`.
* **Дефазификация** методом центра тяжести и подбор ближайшего растения из списка `PLANT`.
* **Нечеткий вход:** для задачи с одним входом значение можно задать как четкое число или как нечеткое число «около x» (треугольник шириной ±δ).
* **Графики и таблицы в окне программы:** выходное множество, сравнение механизмов, сравнение импликаций, функции принадлежности, таблица результатов по тестовым наборам.

## 🖥️ Руководство пользователя

1. **Выбор базы знаний:** кнопки **«Задача 1 — освещённость»** и **«Задача 2 — условия помещения»** загружают готовые файлы, **«Открыть другую базу правил…»** позволяет выбрать свой `.txt`.
2. **Входные значения:** задайте ползунками значения входных переменных («Параметры помещения»).
3. **Настройки вывода:** выберите механизм вывода, тип импликации и оператор агрегации. Для задачи с одним входом доступно поле **«Неопределённость входа (±)»** (по умолчанию `5`): это ширина нечеткого числа «около x», `0` означает четкое значение (синглетон). Для задачи с тремя входами поле скрыто, входы считаются четкими.
4. **Вычисление:** кнопка **«Рассчитать рекомендацию»** показывает центр тяжести, рекомендуемое растение и график выходного множества.
5. **Сравнение:**
   * **«Сравнить механизмы вывода»** рисует на одном графике все три механизма (только задача 1);
   * **«Сравнить импликации»** рисует на одном графике результаты для Мамдани и Ларсена при выбранном механизме и агрегации.
6. **Функции принадлежности:** кнопка **«Показать функции принадлежности»** строит графики термов всех переменных.
7. **Таблица:** кнопка **«Таблица результатов для тестов»** открывает окно с результатами для всех наборов `CASE` из файла правил (для каждой импликации и каждого механизма; агрегация — максимум).

Прочерк `—` в результате означает пустое итоговое множество: центр тяжести не определен.

## 📝 Формат файла базы знаний

Файл состоит из строк пяти типов. Символ `#` обозначает комментарий. Строки с пробелами в названиях заключаются в кавычки.

```text
VAR light IN 0 100 "Освещённость"  # переменная: имя, IN/OUT, минимум, максимум, отображаемое название
SET light low trap 0 0 20 40       # терм: переменная, имя, tri (3 числа) или trap (4 числа)
SET light mid tri 25 50 75
RULE IF light IS low AND time IS little THEN capr IS very_easy
PLANT 1 "Замиокулькас"             # значение выхода, при котором растение подходит, и название
CASE light=15 time=10 temp=20      # тестовый набор для таблицы
```

* `tri a b c` – треугольная функция принадлежности, `trap a b c d` – трапециевидная.
* В правиле условия соединяются связкой `AND` (операция min), заключение одно.
* В базе должна быть ровно одна выходная переменная (`OUT`), хотя бы одно правило и хотя бы одна строка `PLANT`.
* Названия растений записываются в кавычках (`"Фикус Бенджамина"`), значение выхода – перед названием.
* Композиционные механизмы используют только первое условие правила, поэтому применимы к базам с одним входом.

## 🏗️ Архитектура и алгоритм работы

Приложение состоит из двух ключевых компонентов:

1. **`PlantRecommendationApp` (графический интерфейс):** отвечает за взаимодействие с пользователем, загрузку файлов, построение графиков и таблицы.
2. **Ядро нечеткого вывода:**
   * **`triangular`, `trapezoidal`:** функции принадлежности.
   * **`load_knowledge_base(path)`, `validate_knowledge_base(model)`:** чтение и проверка файла базы знаний.
   * **`IMPLICATIONS`, `AGGREGATIONS`:** словари импликаций и операторов агрегации.
   * **`infer_by_firing_levels(...)`:** вывод по уровням истинности предпосылок:
     1. Для каждого условия правила вычисляется степень принадлежности входа терму (для нечеткого входа – высота пересечения).
     2. Условия объединяются через min, получается уровень истинности правила.
     3. По импликации строится выходное множество каждого правила.
     4. Множества правил агрегируются в одно.
   * **`infer_composition_individual(...)`:** композиционный алгоритм 1 – для каждого правила строится отношение `R_i(x, y)`, вычисляется `B'_i = A' ∘ R_i`, затем выходы агрегируются.
   * **`infer_composition_aggregated(...)`:** композиционный алгоритм 2 – по `build_fuzzy_relation(...)` строится агрегированное отношение `R(x, y)`, затем `B' = A' ∘ R` (композиция max-min).
   * **`centroid(...)`, `recommended_plant(...)`:** дефазификация методом центра тяжести и подбор ближайшего растения.

Для импликации Мамдани, композиции max-min и агрегации «Максимум» все три механизма дают одно и то же выходное множество (предложения 1 и 2 лекции).
