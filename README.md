## 📖 Описание проекта

Проект представляет собой программную оболочку экспертной системы для подбора комнатных растений в зависимости от условий помещения (освещение, полив, сложность ухода, безопасность для домашних животных).

В основе работы приложения лежит **алгоритм прямого логического вывода (Forward Chaining)**. Система отлкивается от заданного набора начальных фактов и последовательно активирует правила из базы знаний, пополняя рабочей память промежуточными фактами, пока не будет получен итоговый результат (конкретное растение).

---

## ✨ Особенности системы

* **Разделение базы знаний и движка вывода:** Все правила хранятся в отдельном текстовом файле `rules.txt` и не зашиты в исходный код программы.
* **Редактирование правил "на лету":** Встроенный GUI позволяет просматривать, дополнять и сохранять базу правил напрямую из интерфейса без открытия сторонних редакторов.
* **Промежуточные рассуждения:** Поддержка промежуточных категорий (например: `освещение = яркое` $\rightarrow$ `группа = светолюбивые` $\rightarrow$ `растение = Кактус`).
* **Отсутствие сторонних зависимостей:** Проект написан на чистом **Python** с использованием штатного графического фреймворка **Tkinter**.
